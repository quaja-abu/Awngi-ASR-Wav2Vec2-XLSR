# Data documentation

No audio recordings or restricted participant data are stored in this repository.

Before adding any dataset-derived material, verify:
- institutional ethics approval and consent conditions;
- whether the material may be shared publicly or only by controlled request;
- anonymization and re-identification risks;
- exact correspondence between the files, notebook, and manuscript.

Dataset partitions, speaker identifiers, transcription files, and metadata remain pending verification. Do not upload raw audio, identifiable information, consent forms, or confidential records.
