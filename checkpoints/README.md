# Training Checkpoints

This directory documents model checkpoints generated
during the Awngi XLS-R ASR reproduction experiment.

## Training Configuration

- Model: facebook/wav2vec2-xls-r-300m
- Learning rate: 3e-5
- Maximum training steps: 24,500
- Batch size: 1
- Gradient accumulation: 4
- Progressive feature encoder unfreezing: 3,000 steps

## Checkpoint Storage

Full training checkpoints are preserved in Google Drive.
This directory contains checkpoint documentation and metadata.

Training is ongoing.
