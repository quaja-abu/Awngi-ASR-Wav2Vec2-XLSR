# Model artifacts

The final trained acoustic-model checkpoint associated with the originally reported experiments is currently unavailable. Recovery is being investigated.

An incomplete checkpoint may exist locally, but it must not be represented as the final model. Do not upload checkpoint fragments until their contents, provenance, and usefulness have been inspected.

Any future retraining run must be versioned and documented separately from the original experiment. Record the configuration, random seed, software versions, dataset split identifiers, training step, and evaluation outputs.
