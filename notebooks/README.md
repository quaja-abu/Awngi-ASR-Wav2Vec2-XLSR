# Research notebooks

This directory contains the Jupyter notebooks used for the Awngi ASR experiments.

## Before committing a notebook

- Remove embedded audio, participant identifiers, access tokens, API keys, and private paths.
- Check that notebook outputs do not expose restricted data or identifiable information.
- Keep the original notebook unchanged in a separate secure location.
- Record the notebook filename, date, and whether it reproduces the original experiment or a later reproduction run.

The original experiment notebook is to be added after a privacy and consistency review.
